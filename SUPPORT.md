# Getting Support for Dakly

We are here to help you get the most out of **Dakly**. Depending on the nature of your question or issue, please use the appropriate channel below.

---

## 1. Documentation & Self-Help
Before opening an issue, check the official documentation:
- **[Main README](README.md)**: Quickstart, API guides, and code examples
- **[Architecture Deep Dive](docs/ARCHITECTURE.md)**: Technical overview of pacing, queues, and security
- **[REST API Reference](docs/API_REFERENCE.md)**: Detailed endpoints, request headers, error codes
- **[Webhooks Guide](docs/WEBHOOKS.md)**: Event catalog and HMAC signature verification
- **[SDK Documentation](docs/SDK_GUIDE.md)**: Quick reference for Node.js and Python SDKs

---

## 2. Asking Questions & Community Discussion
For general usage questions, architecture advice, or integration assistance:
- **[GitHub Discussions](https://github.com/parthpatil1234p-svg/Dakly/discussions)**: Ideal for "How do I do X?" questions, sharing templates, or discussing feature ideas.

---

## 3. Reporting Bugs
If you have discovered a bug in Dakly:
- Check existing **[GitHub Issues](https://github.com/parthpatil1234p-svg/Dakly/issues)** to see if the problem has already been reported.
- If not, use the **[Bug Report Form](https://github.com/parthpatil1234p-svg/Dakly/issues/new?template=bug_report.yml)**.
- Include minimal reproducible code, error messages, and system environment details.

---

## 4. Requesting New Features
Have an idea for a new email template, SDK wrapper, or integration?
- Submit a proposal via the **[Feature Request Form](https://github.com/parthpatil1234p-svg/Dakly/issues/new?template=feature_request.yml)**.

---

## 5. Security Vulnerabilities
Do **NOT** report security vulnerabilities via public issues or discussions.
- Follow the guidelines in our **[Security Policy](SECURITY.md)**.
- Use **[GitHub Private Security Advisories](https://github.com/parthpatil1234p-svg/Dakly/security/advisories/new)** or email [support@dakly.dev](mailto:support@dakly.dev).

---

## 6. Commercial & Private Support
For mission-critical production inquiries, custom enterprise deployment, or sponsorship:
- Email: [support@dakly.dev](mailto:support@dakly.dev)
- Live Dashboard: [https://dakly.vercel.app](https://dakly.vercel.app)
