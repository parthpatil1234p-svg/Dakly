# 🎨 Dakly Brand Voice & Copywriting Guidelines

> **Canonical Brand Voice Standards for Dakly Core, UI, Documentation, and SDKs.**  
> Derived from global engineering brand standards to ensure every touchpoint communicates with craft, confidence, and zero filler.

---

## 1. Brand Identity & Philosophy
- **Personality**: Confident, sharp, human, and craft-obsessed.
- **Tone Spectrum**: Conversational yet authoritative. Never stuffy, never robotic, never artificially cheerful.
- **Signal-to-Noise**: Maximum information density, zero throat-clearing, zero fluff.

---

## 2. Voice Dimensions
| Dimension | Position | Guideline |
| :--- | :--- | :--- |
| **Formality** | Approachable Professional | Write like an elite engineer or founder talking directly to a respected peer. |
| **Clarity** | Direct & Punchy | State the fact or action first. Use active voice and concrete nouns. |
| **Emotion** | Authentic & Grounded | Real enthusiasm backed by facts, never unearned hype or corporate cheerleading. |
| **Humor / Wit** | Subtle & Tactical | Dry, knowing, or playfully crisp when appropriate — never cheesy or distracting. |

---

## 3. Strict Anti-AI & Anti-Cliché Rules

### 🚫 Strictly Banned AI Tropes & Generic Words
- **Banned Openers**: 
  - *"In today's fast-paced digital landscape..."*
  - *"Let's dive in..."*
  - *"Whether you are a... or a..."*
  - *"In this section, we will explore..."*
- **Banned Clichés**: 
  - *seamless*, *supercharge*, *game-changer*, *revolutionary*, *delve*, *beacon*, *tapestry*, *testament to*, *bespoke*, *cutting-edge*, *leverage*, *paradigm shift*, *look no further*, *robust (overused)*.
- **Banned Connectors**: 
  - Overly repetitive *"Furthermore"*, *"Moreover"*, *"Additionally"*, *"In conclusion"*, *"Needless to say"*.
- **Banned Microcopy**: 
  - *"Click here"*, *"Submit"*, *"An error occurred"*, *"Something went wrong"*, *"Lorem ipsum"*.

### ✅ Preferred Natural Language
- **Action Verbs**: 
  - *Ship, build, wire, verify, trace, launch, inspect, measure, fix, automate, dispatch, deliver.*
- **Human Microcopy**:
  - Instead of *"An error occurred"*: *"We couldn't reach the server. Let's give it another spin."*
  - Instead of *"Click here"*: *"Explore live demo"*, *"View source"*, *"Inspect pipeline"*, *"Test API Key"*.
  - Instead of *"Welcome to our platform"*: *"Build without friction."*
  - Instead of *"Submit"*: *"Send Invite"*, *"Save Project"*, *"Deliver Template Email"*.

---

## 4. UI & Context-Sensitive Tone Shifts
1. **Primary UI / Hero**: 
   - Punchy, bold, promise-driven. Clear value proposition in the first sentence.
2. **Documentation & Guides**: 
   - Crisp, crystal-clear, example-backed. Code snippets precede abstract explanations.
3. **Error Handling & Fallbacks**: 
   - Calm, empathetic, diagnostic, and actionable. Always tell the developer *why* it failed and the exact step to unblock it.
4. **Success States & Notifications**: 
   - Brief, understated confirmation (`Delivered in 420ms`, `Copied API Key!`, `1:1 Logo Verified`).

---

## 5. Maintenance Checklist
- [x] All buttons use concrete action verbs (`Sign In to Console`, `Create Project`, `Block Email`).
- [x] All docs prioritize code examples and curl requests over boilerplate intros.
- [x] No banned clichés (*seamless*, *supercharge*, *game-changer*) in UI copy or documentation.
- [x] Error messages provide actionable remediation guidance.
